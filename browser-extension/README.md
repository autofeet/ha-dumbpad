# DumbPad · 轻量版 0.2.0

点击浏览器工具栏里的蓝色 DumbPad 图标，在原生侧栏打开现有 HA 笔记。沿用网页 PIN；不保存 PIN、不另存笔记、不读取其他网站、不添加额外标题栏。

## 安装

1. 解压 ZIP。打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择含有 `manifest.json` 的文件夹；直接使用仓库时选择 `browser-extension` 文件夹。
4. 将“DumbPad”固定到浏览器工具栏，点击蓝色图标。
5. 按网页原有方式输入 PIN。面板只为当前标签页打开；未记录的新页面默认关闭。关闭按钮由浏览器提供。

## 页面记录与外观

- 按网页地址区分上次选中的笔记。再次访问该网页并点击 DumbPad，会加载之前那本笔记。
- 分别保存每个网页上一次的展开/关闭状态。切回原标签页或返回已记录网页时，恢复对应的面板配置及笔记。
- 没记录的新页面默认关闭；曾手动关闭的页面也保持关闭。相同网页的刷新保留当前状态。
- 展开面板受浏览器用户操作规则控制：若浏览器不自动恢复新实例，需要点一下图标，随后仍恢复原来的笔记。扩展不通过后台调用强制弹出。
- 只在浏览器本地保存网页的非加密标识和笔记编号，不保存网页正文、原始网址、PIN 或笔记正文，也不上传这些记录。该标识用于匹配网页，并不提供密码学保护。
- 浏览器新标签页、设置页等内部页面不保留跨会话记录。
- 插件名称为 DumbPad；笔记内工具栏、编辑区和菜单圆角为 4px，笔记下拉框为 3px。

需要 Chromium 142 或更新版本，以支持原生面板的打开/关闭事件。Chrome 与 Edge 共用这一份源码；实际测试记录以交付说明为准。

## 数据与权限

- 使用 `sidePanel`、`tabs`、`storage` 和 `https://dumbpad.piggydamn.club/*` 的站点权限。
- `tabs` 用于在切换或跳转时获取打开标签页的地址，以匹配此前保存的状态；不调用浏览历史 API，也不读取其他网站正文。浏览器可能将此权限显示为“读取浏览记录”。`storage` 只保存本地网页标识、展开状态和笔记编号。
- 站点权限用于嵌入页面的登录与存储兼容。Chrome 的站点权限匹配不区分端口，但框架地址和扩展 CSP 固定为 HTTPS 99 端口。
- 仅在 DumbPad 嵌入页运行样式和笔记选择桥接脚本，不向其他网站注入脚本。不申请 Cookie API 或剪贴板读取权限。
- 笔记和 PIN 验证仍由原 HA 服务处理，iframe 页面无法访问扩展 API；扩展不收集数据。
- HA 服务必须可访问。本版不提供独立离线笔记或单独的同步逻辑。

## 更新与排查

HA 网页继续沿用现有 GitHub 自动更新。这个“加载已解压”扩展本身不会从 GitHub 自动安装新版；更新扩展文件后，请在扩展管理页点击“重新加载”。

若侧栏登录异常，先确认普通标签页能打开该 DumbPad 地址，并检查扩展的 DumbPad 站点访问权限。不要关闭 PIN、浏览器全局隐私保护或证书验证。若仍无法登录，请记录浏览器版本及第三方 Cookie 设置用于排查。

关闭侧栏期间网页可能被浏览器释放；已保存的笔记保留在 HA，重新打开时重新加载。移除插件不会删除 HA 中的笔记。
